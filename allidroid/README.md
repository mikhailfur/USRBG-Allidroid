# USRBG для Allidroid

Мобильный порт [плагина USRBG](https://github.com/Vendicated/Vencord/tree/main/src/plugins/usrbg) из Vencord: показывает баннеры из базы USRBG у пользователей, у которых нет Nitro.

Плагин сделан в формате **user plugin** Allidroid: его можно добавить по ссылке в приложении и не пересобирать клиент.

## Установка

1. В Allidroid открой **Plugins → Add a user plugin**.
2. Вставь ссылку:
   ```
   https://cdn.jsdelivr.net/gh/mikhailfur/USRBG-Allidroid@v1.0.1/allidroid/
   ```
3. Включи **USRBG** в списке плагинов.

Ссылка должна указывать на папку, где лежат `manifest.json` и `index.js`. `raw.githubusercontent.com` для папки не подходит: он отдаёт только отдельные файлы, поэтому URL папки без `manifest.json` вернёт 404.

При первом запуске Allidroid может предупредить, что плагин не из официального списка. Это нормально: user plugin просто выполняет код внутри приложения.

## Что делает

- Подставляет баннер USRBG в профиль пользователя, если у него нет баннера Nitro.
- Работает в профилях из личных сообщений, списка участников и серверов.
- Если у пользователя есть и Nitro-баннер, и USRBG, по умолчанию показывается USRBG. Включи **Сначала баннер Nitro**, если хочешь видеть Nitro-баннер.
- Список баннеров загружается с `https://usrbg.is-hardly.online/users` (около 6 МБ) и хранится в памяти. Повторная загрузка запускается не чаще раза в 6 часов.

## Настройки

Открываются кнопкой с гаечным ключом на карточке плагина.

- **Сначала баннер Nitro** — если включено, у пользователей с Nitro-баннером показывается он, а не USRBG.
- **Обновить список баннеров** — принудительно скачать свежую базу и показывает, сколько баннеров загружено.
- **Получить свой баннер** — ссылка на инструкцию USRBG, как добавить себя в базу.

## Если баннер не появился

1. Проверь, что плагин включён, и открой его настройки.
2. В блоке **Диагностика** посмотри:
   - загружена ли база (количество в строке обновления);
   - активны ли патчи;
   - найден ли твой баннер и есть ли у тебя баннер Nitro.
3. Если в строке **Проверить мой баннер** написано `Nitro: да`, а переключатель **Сначала баннер Nitro** включён, USRBG намеренно скрыт. Выключи переключатель.
4. Если база не загрузилась, нажми **Обновить список баннеров** и проверь интернет.
5. После обновления плагина нажми **Refetch** на его карточке или удали и добавь заново.

## Чем отличается от десктопной версии

Десктопный USRBG умеет ещё подставлять баннеры как фон плиток в голосовом канале. В мобильном Discord плитки голосового канала рисуют градиент из цветов профиля, а не картинку-фон, поэтому эта настройка в порт не перенесена. Всё остальное поведение сохранено.

## Как это работает

Плагин патчит `DisplayProfile.prototype.getBannerURL` и функции `getUserBannerURL` / `getGuildMemberBannerURL` из `AvatarUtils`:

- если у профиля нет Nitro-баннера, возвращается ссылка на USRBG;
- если Nitro-баннер есть и включён `nitroFirst`, возвращается оригинальный URL;
- если `nitroFirst` выключен, USRBG имеет приоритет.

Дополнительно плагин подменяет профиль в хуке `useDisplayProfile` и в компоненте `UserProfileBanner`, чтобы баннер появлялся даже там, где Discord рисует профиль не через `getBannerURL`. Для своего аккаунта проверяется прямой URL картинки, даже если список ещё не загрузился или устарел.

После загрузки списка плагин вызывает `emitChange` у `UserStore` и `UserProfileStore`, чтобы открытые профили перерисовались.

## Сборка

```bash
cd allidroid
npm install
npm run build
```

`build.mjs` собирает `src/index.tsx` в `index.js` и обновляет `hash` в `manifest.json`. После изменений заново выложи `manifest.json` и `index.js`.

## Файлы

- `src/index.tsx` — исходник.
- `index.js` — готовый бандл для Allidroid.
- `manifest.json` — манифест user plugin.
- `build.mjs` — сборка.
